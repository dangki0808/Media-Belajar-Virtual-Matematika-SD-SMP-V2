Modul 2 · Aljabar

Persamaan Kuadrat

Tujuan Pembelajaran
  • Menyelesaikan persamaan kuadrat dengan pemfaktoran, melengkapkan kuadrat sempurna, dan rumus ABC.
  • Menentukan jenis akar dengan diskriminan serta jumlah dan hasil kali akar.
  • Menyusun persamaan kuadrat dan memodelkan masalah nyata.

1. Bentuk umum

ax² + bx + c = 0 dengan a ≠ 0. Nilai x yang memenuhi disebut akar (penyelesaian).

Contoh: x² − 5x + 6 = 0 (a = 1, b = −5, c = 6). Akarnya 2 dan 3 karena 2² − 10 + 6 = 0 dan 3² − 15 + 6 = 0.

2. Pemfaktoran

Untuk x² + bx + c: cari dua bilangan p dan q dengan p × q = c dan p + q = b. Maka x² + bx + c = (x + p)(x + q).

x² − 5x + 6 = 0
(x − 2)(x − 3) = 0
x = 2 atau x = 3
x² − 9 = 0
(x + 3)(x − 3) = 0
x = ±3
x² − 4x = 0
x(x − 4) = 0
x = 0 atau x = 4
a ≠ 1 2x² + 7x + 3 = 0: cari p × q = a·c = 6 dan p + q = 7 → 1 dan 6.
2x² + x + 6x + 3 = x(2x + 1) + 3(2x + 1) = (2x + 1)(x + 3) → x = −½ atau x = −3
Sifat kunci: jika A × B = 0, maka A = 0 atau B = 0.

3. Melengkapkan kuadrat sempurna

  1. x² + 6x + 2 = 0 → x² + 6x = −2
  2. Tambahkan (½ × 6)² = 9 pada kedua ruas: x² + 6x + 9 = 7
  3. (x + 3)² = 7 → x + 3 = ±√7 → x = −3 ± √7

4. Rumus ABC dan diskriminan

x = −b ± √(b² − 4ac)2a
D = b² − 4ac disebut diskriminan
Nilai DJenis akar
D > 0dua akar real berbeda
D = 0dua akar real kembar (sama)
D < 0tidak mempunyai akar real
Contoh x² + 2x − 4 = 0: D = 4 + 16 = 20 → x = (−2 ± 2√5)/2 = −1 ± √5
Akar kembar x² − 6x + k = 0 berakar kembar jika D = 36 − 4k = 0 → k = 9.

5. Jumlah dan hasil kali akar

x₁ + x₂ = −ba
x₁ × x₂ = ca

Persamaan kuadrat yang akarnya x₁ dan x₂: x² − (x₁ + x₂)x + x₁x₂ = 0. Akar 3 dan −2 → x² − x − 6 = 0.

Soal cerita Luas persegi panjang 60 cm², panjangnya 4 cm lebih dari lebarnya. l(l + 4) = 60 → l² + 4l − 60 = 0 → (l + 10)(l − 6) = 0 → l = 6 cm (l = −10 tidak mungkin).

Persamaan x² + bx + c = 0. Daftar di bawah berisi semua pasangan p × q = c. Pasangan yang jumlahnya b akan menyala.
