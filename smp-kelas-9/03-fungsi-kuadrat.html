Fungsi Kuadrat

Tujuan Pembelajaran
  • Menggambar grafik fungsi kuadrat (parabola) dan menjelaskan pengaruh nilai a, b, dan c.
  • Menentukan sumbu simetri, titik puncak, nilai maksimum/minimum, dan titik potong dengan sumbu.
  • Menyelesaikan masalah optimasi sederhana dengan fungsi kuadrat.

1. Bentuk dan grafik

f(x) = ax² + bx + c, a ≠ 0. Grafiknya berbentuk parabola.
NilaiPengaruh pada grafik
a > 0 / a < 0terbuka ke atas (punya nilai minimum) / ke bawah (punya nilai maksimum)
|a| besar / kecilparabola makin sempit / makin lebar
ctitik potong sumbu Y di (0, c)
b (bersama a)menggeser sumbu simetri x = −b/2a ke kiri atau kanan
D = b² − 4acD > 0 memotong sumbu X di dua titik, D = 0 menyinggung, D < 0 tidak memotong

2. Sumbu simetri dan titik puncak

Sumbu simetri: x = −b2a
Titik puncak: (−b2a, −D4a)
Contoh y = x² − 4x + 3 → x = 4/2 = 2, y = 4 − 8 + 3 = −1. Puncak (2, −1), nilai minimum −1.

Bentuk puncak: y = a(x − h)² + k dengan puncak (h, k). Contoh puncak (1, 2) melalui (0, 3): 3 = a(1) + 2 → a = 1 → y = (x − 1)² + 2 = x² − 2x + 3.

3. Langkah menggambar grafik

  1. Tentukan arah buka dari tanda a.
  2. Titik potong sumbu Y: (0, c).
  3. Titik potong sumbu X: selesaikan ax² + bx + c = 0 (jika D ≥ 0).
  4. Sumbu simetri dan titik puncak.
  5. Hubungkan titik-titik dengan kurva mulus yang simetris.
y = x² − x − 6: buka ke atas, potong Y di (0, −6), potong X di (−2, 0) dan (3, 0), puncak (½, −6¼).

4. Masalah maksimum–minimum

Luas maksimum Kawat 40 cm dibentuk persegi panjang. Jika panjang x, lebar 20 − x. Luas L = x(20 − x) = −x² + 20x. Puncak x = 10 → L maks = 100 cm² (bentuknya persegi).
Lintasan bola h(t) = 20t − 5t². Puncak t = 20/10 = 2 detik, tinggi maksimum h(2) = 40 − 20 = 20 m.
