Pola Bilangan dan Barisan

Tujuan Pembelajaran
  • Mengenali pola bilangan (ganjil, genap, persegi, persegi panjang, segitiga, Pascal, Fibonacci) dari susunan objek.
  • Menentukan suku berikutnya dan rumus suku ke-n barisan aritmetika dan geometri.
  • Menghitung jumlah n suku pertama deret aritmetika dan menerapkannya dalam masalah nyata.

1. Pola bilangan istimewa

PolaBarisanSuku ke-n
Bilangan ganjil1, 3, 5, 7, …2n − 1
Bilangan genap2, 4, 6, 8, …2n
Persegi1, 4, 9, 16, …n²

Jumlah n bilangan ganjil pertama = n². Contoh: 1 + 3 + 5 + 7 = 16 = 4². Lihat buktinya pada pola persegi di Lab!

2. Barisan aritmetika

Selisih dua suku berurutan selalu sama, disebut beda (b).

Un = a + (n − 1)b   dengan a = suku pertama, b = U2 − U1
Contoh 3, 7, 11, 15, … → a = 3, b = 4. U20 = 3 + 19 × 4 = 79. Rumus umumnya Un = 3 + (n − 1)4 = 4n − 1.

3. Deret aritmetika

Deret adalah jumlah suku-suku barisan.

Sn = n2(2a + (n − 1)b) = n2(a + Un)
Cara Gauss 1 + 2 + … + 100: pasangkan 1 + 100, 2 + 99, … ada 50 pasang bernilai 101 → 5.050.

4. Barisan geometri

Perbandingan dua suku berurutan selalu sama, disebut rasio (r).

Un = a × rn−1   dengan r = U2 : U1
Contoh 2, 6, 18, … → r = 3. U5 = 2 × 34 = 162.
Bakteri membelah menjadi 2 setiap 20 menit. Awalnya 5 bakteri. Setelah 2 jam (6 kali membelah): 5 × 26 = 320.
