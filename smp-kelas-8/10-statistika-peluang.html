Statistika dan Peluang

Tujuan Pembelajaran
  • Menentukan ukuran pemusatan dan ukuran penyebaran data (jangkauan, kuartil, jangkauan interkuartil).
  • Menentukan ruang sampel dan peluang teoretik suatu kejadian.
  • Membandingkan peluang empirik hasil percobaan dengan peluang teoretik dan menghitung frekuensi harapan.

1. Ukuran pemusatan (mengingat kembali)

Mean = jumlah data : banyak data. Median = nilai tengah data terurut. Modus = data yang paling sering muncul.

2. Ukuran penyebaran

Dua kelas bisa punya rata-rata sama tetapi sebarannya berbeda. Ukuran penyebaran menunjukkan seberapa jauh data menyebar.

  1. Urutkan data dari terkecil.
  2. Q₂ (kuartil tengah) = median seluruh data.
  3. Q₁ (kuartil bawah) = median data di kiri Q₂, Q₃ (kuartil atas) = median data di kanan Q₂. Jika banyak data ganjil, data tengah tidak diikutkan.
UkuranRumus
Jangkauandata terbesar − data terkecil
Jangkauan interkuartilQ₃ − Q₁
Simpangan kuartil½(Q₃ − Q₁)
Contoh 3, 5, 6, 7, 8, 9, 12 → Q₂ = 7. Bagian kiri 3, 5, 6 → Q₁ = 5. Bagian kanan 8, 9, 12 → Q₃ = 9. Jangkauan interkuartil = 9 − 5 = 4.

3. Ruang sampel dan kejadian

  • Percobaan: kegiatan yang hasilnya tidak pasti, misalnya melempar dadu.
  • Ruang sampel (S): himpunan semua hasil yang mungkin. Dadu: S = {1, 2, 3, 4, 5, 6}, n(S) = 6.
  • Titik sampel: setiap anggota ruang sampel.
  • Kejadian (A): himpunan bagian dari S, misalnya "muncul bilangan genap" A = {2, 4, 6}.

Dua koin: S = {AA, AG, GA, GG} (A = angka, G = gambar), n(S) = 4. Dua dadu: n(S) = 6 × 6 = 36.

4. Peluang

Peluang teoretik
P(A) = n(A)n(S)
Peluang empirik (hasil percobaan)
= banyak kejadian A munculbanyak percobaan
  • 0 ≤ P(A) ≤ 1. P = 0 → kejadian mustahil (dadu muncul 7). P = 1 → kejadian pasti.
  • Komplemen: P(bukan A) = 1 − P(A). P(hujan) = 0,3 → P(tidak hujan) = 0,7.
  • Frekuensi harapan: Fh = P(A) × banyak percobaan. Dadu dilempar 120 kali → harapan mata 6 muncul = 16 × 120 = 20 kali.
Makin banyak percobaan, peluang empirik cenderung makin dekat ke peluang teoretik. Buktikan di Lab Simulasi!
Contoh Kantong berisi 5 kelereng merah, 3 biru, 2 hijau. P(biru) = 310. Dua dadu, P(jumlah 7) = 636 = 16.
